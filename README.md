# EV Green Technology Website

A mobile-responsive **Green Technology website focused on Electric Vehicles (EVs)**, designed to introduce users to EV technology, environmental benefits, charging solutions, and sustainable transportation. The website combines modern UI/UX design with interactive front-end features to provide an engaging and informative user experience.

## 🚀 Key Features

* **EV Education** — Introduces electric vehicles, their components, operation, and key technologies.
* **Sustainable Transportation** — Highlights how EVs contribute to cleaner and more sustainable mobility.
* **Interactive Web Pages** — Provides interactive elements using JavaScript and jQuery.
* **Responsive Design** — Optimized for desktop, tablet, and mobile screen sizes.
* **Modern UI/UX** — Uses structured layouts, visual elements, navigation menus, and responsive components.
* **Client-Side Storage** — Utilizes web storage technologies to maintain selected user information and preferences.
* **Dynamic Content** — Uses JavaScript and jQuery to enhance website interaction and content presentation.
* **Bootstrap Integration** — Uses Bootstrap components and responsive utilities to support consistent layouts across devices.

## 🛠️ Technical Stack

* **HTML5** — Website structure and semantic content
* **CSS3** — Styling, layouts, animations, and responsive design
* **JavaScript** — Client-side functionality and interactive features
* **jQuery** — DOM manipulation and dynamic web interactions
* **Bootstrap** — Responsive layouts and UI components

## 💾 Web Storage

Different browser storage technologies are incorporated to demonstrate client-side data management:

### Local Storage

Used to store information that should remain available after the browser is closed and reopened.

### Session Storage

Used for temporary information that only needs to remain available during the current browsing session.

### Cookies

Used to store small pieces of information that can be accessed by the website across requests.

These technologies demonstrate how front-end applications can manage user-related information without requiring a traditional database.
